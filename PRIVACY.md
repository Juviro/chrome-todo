# Privacy Policy – Todo (Chrome extension)

_Last updated: 17 September 2026_

Todo is a todo list that replaces the Chrome new tab page. It is built so that it does not need to know anything about you.

## What data the extension handles

The extension stores only what you type into it: todo groups, todo texts, notes, the list of recently completed todos, and the time of your last backup.

## Where the data is stored

- **On your device**, in Chrome's extension storage (`chrome.storage.local`).
- **In your Chrome profile's sync storage** (`chrome.storage.sync`), so that the same lists appear in every browser where you are signed in to Chrome with sync enabled. This storage is operated by Google as part of Chrome sync and is tied to your Google account. The extension has no access to any account information.

## What the extension does not do

- It has **no server** and makes **no network requests** of its own.
- It does **not collect, transmit, sell or share** any personal data, usage data or analytics.
- It does not use cookies, tracking, advertising or third-party services.
- It does not load remote code.

## Permissions

The only permission requested is `storage`, which is required to save your todos locally and in Chrome sync as described above.

## Backups

The «Download backup» button writes a JSON file with your todos to your computer. The file stays wherever you save it; the extension never uploads it.

## Deleting your data

Removing the extension deletes its local storage. Data in Chrome sync storage is removed by Chrome when the extension is uninstalled from all synced browsers, or can be cleared by resetting Chrome sync in your Google account settings.

## Changes and contact

If this policy changes, the updated version is published in this repository. Questions: open an issue in this repository.
